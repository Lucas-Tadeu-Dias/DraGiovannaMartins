COMO EXECUTAR

1. Instale o .NET 8 SDK.
2. Abra esta pasta no Visual Studio 2022 ou VS Code.
3. Execute: dotnet restore
4. Execute: dotnet run
5. Abra o endereço mostrado no terminal.

Antes de publicar, adicione uma foto profissional autorizada e confirme tratamentos, dados de contato e política de privacidade.
